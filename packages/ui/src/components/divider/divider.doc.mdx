# Divider

## What Divider is for

`Divider` is a thin presentational separator — a hairline rule between
content sections. Reach for it whenever you would otherwise write `border-t`
on a `<hr>`. Both axes are supported, and the same primitive carries the
right `role="separator"` + `aria-orientation` ARIA semantics in either
orientation.

## Props

- **`orientation`** — `"horizontal"` (default) or `"vertical"`.
- **`tone`** — `"subtle"` / `"default"` / `"strong"`. Maps onto the Genuin
  DS `secondary-100` / `secondary-150` / `secondary-300` background-color
  scale. `default` is the canonical 1px hairline.
- **`inset`** — `"none"` (default) / `"sm"` / `"md"` / `"lg"`. Horizontal
  inset applied to both ends. Honoured only for horizontal orientation;
  silently ignored for vertical.
- **`asChild`** — Render as a different element (e.g. `<hr>`) via Radix Slot.

All standard `HTMLDivElement` attributes are forwarded.
