# Stack

## What Stack is for

`Stack` is the ergonomic shortcut for the most common layout pattern in the app:
a vertical list of things separated by a consistent gap. No alignment knobs, no
direction toggle — just a column with a `gap`. Reach for it whenever you would
otherwise write `flex flex-col gap-N` on a `<div>`.

When you need horizontal-vs-vertical alignment control, justification, or
flex-wrap, use [`Column`](?path=/docs/layout-column--docs) or
[`Row`](?path=/docs/layout-row--docs) instead.

## Props

- **`gap`** — Vertical spacing between children. Named DS token from the
  Padding scale (`none` / `xxs` / `xs` / `sm` / `md` / `ml` / `lg` / `xl` /
  `xxl`). Defaults to `"md"` (16 px).
- **`asChild`** — Render as a different element (e.g. `<section>`, `<main>`,
  `<ul>`) via Radix Slot. Useful for preserving semantics without nesting.

All standard `HTMLDivElement` attributes are forwarded.
