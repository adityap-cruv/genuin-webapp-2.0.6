# Genuin Web SDK Examples

This directory contains examples demonstrating how to use the Genuin Web SDK.

## Examples

### 1. Vanilla JavaScript

- `vanilla-js/` - Basic HTML/JS implementation
- `vanilla-js-advanced/` - Advanced features and event handling

### 2. React

- `react-basic/` - Basic React component usage
- `react-advanced/` - Advanced React patterns with context and hooks

### 3. Next.js

- `nextjs/` - Integration with Next.js applications

### 4. Migration Examples

- `migration/` - Examples showing how to migrate from legacy SDK to new SDK

## Quick Start

Each example directory contains:

- `README.md` - Specific setup instructions
- `index.html` or equivalent entry file
- Source code demonstrating the feature

## Running Examples

1. Navigate to the specific example directory
2. Follow the README instructions for that example
3. Most examples can be run with a simple HTTP server
