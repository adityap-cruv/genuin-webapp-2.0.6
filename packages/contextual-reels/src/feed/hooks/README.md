# Feed Hooks

| Hook                   | Purpose                                                                                                                                               | Key Constants                                                                        |
| ---------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| `useVerticalSwipe`     | Pointer-events based vertical swipe detection; fires onNext/onPrev when distance or velocity thresholds are met                                       | `SWIPE_THRESHOLD = 0.25` (25% of container height), `VELOCITY_THRESHOLD = 0.4` px/ms |
| `useWheelNavigation`   | Wheel/mousewheel navigation with cooldown guard; prevents accidental rapid swipes                                                                     | `thresholdDelta = 10`, `thresholdTime = 300ms`                                       |
| `useSnapScroll`        | IntersectionObserver-based snap index reporting; debounced to avoid intermediate states                                                               | `SNAP_THRESHOLD = 0.6`, `DEFAULT_DEBOUNCE_MS = 150`                                  |
| `useFeedNavigation`    | Orchestrator composing useVerticalSwipe + useWheelNavigation + useSnapScroll; manages activeIndex, goNext/goPrev/goTo, and timerTracker for analytics | `SWIPE_DEBOUNCE_MS = 150`                                                            |
| `useInactivityAdvance` | 10s inactivity timer; auto-advances feed when isActive=true; resets on pointer/click/touch                                                            | `DEFAULT_TIMEOUT_MS = 10000`                                                         |
| `useFullscreenClasses` | CSS class toggles for fullscreen and mobile modes; manages document.body 'expand'/'mobile' classes                                                    | Width threshold: `≤ 200px` triggers 'mobile' class                                   |
| `useGenAiSwipeGate`    | Gates swipe navigation during GenAI data loading; pauses video on dataReceived; auto-advances after chatClosed with swipe-to-next                     | Auto-advance delay: `5000ms`                                                         |
