Contextual Reels — CDN deploy verification

Loads the published CXR build straight from a CDN host to verify a deploy (that the loader, CSS, entry, and all chunks resolve relative to the host — not a local build). Serve this over HTTP (not file://, which breaks the app's API/CORS calls):

npm run verify:cdn then open the printed URL, and watch the Network panel — every gen_ext*.js / chunks/*.js / assets/*.css request must come from the host below and return 200.

Override via query params: ?host=<base>&version=<v>&tag=<tagId> — e.g. ?host=https://media.begenuin.com (Oracle/prod), ?host=https://media.qa.begenuin.com (QA). Defaults: Bunny pull-zone, version 1.0.0.
